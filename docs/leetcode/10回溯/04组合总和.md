# 组合总和

## TOPIC


给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 target 的不同组合数少于 150 个。

### 示例 1：

输入：`candidates = [2,3,6,7], target = 7`

输出：`[[2,2,3],[7]]`

解释：

2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。

### 示例 2：

输入: `candidates = [2,3,5], target = 8`

输出: `[[2,2,2,2],[2,3,3],[3,5]]`

### 示例 3：

输入: `candidates = [2], target = 1`

输出: `[]`

#

这题还是熟悉的味道：**回溯 + 剪枝** 👀
区别在于：

- 数字可以**重复使用**
- 但组合里数字顺序不区分（`[2,2,3]` 和 `[2,3,2]` 视为同一种，要避免）

---

## 🧠 思路整理

### 1. 回溯框架

我们需要搜所有“和为 target 的组合”，用一个 `path` 记录当前选的数字，`sum` 记录当前和。

递归函数大致长这样：

```js
backtrack(startIndex, sum);
```

参数含义：

- `startIndex`：本轮搜索从 `candidates` 的哪个下标开始

  - 关键：**为了避免重复组合（不同顺序）**，后面的递归只能从当前或之后的元素选，不能回头。

- `sum`：当前 `path` 中数字的总和

### 2. 终止条件

- 如果 `sum === target`：找到一种组合，加入结果
- 如果 `sum > target`：直接剪枝返回（继续加只会更大）

### 3. 数字可以重复用怎么办？

在循环中，当我们选择了 `candidates[i]` 后，递归调用依然传 `i`，而不是 `i + 1`：

```js
backtrack(i, sum + candidates[i]);
```

表示：**当前数字可以再次被选**。

---

## ✅ 代码实现（JavaScript）

```js
/**
 * @param {number[]} candidates
 * @param {number} target
 * @return {number[][]}
 */
var combinationSum = function (candidates, target) {
  const res = [];
  const path = [];

  const backtrack = (startIndex, sum) => {
    if (sum === target) {
      res.push(path.slice()); // 拷贝一份当前组合
      return;
    }
    if (sum > target) {
      return; // 超了，剪枝
    }

    for (let i = startIndex; i < candidates.length; i++) {
      const num = candidates[i];
      path.push(num); // 选择当前数字
      backtrack(i, sum + num); // 传 i（可以重复使用当前数字）
      path.pop(); // 回溯，撤销选择
    }
  };

  backtrack(0, 0);
  return res;
};
```

## 🔍 用示例：`candidates = [2,3,6,7], target = 7`

搜索过程（简略版）：

- 选 2 开始：

  - `2` → sum=2

    - 再选 2 → `2,2` → sum=4

      - 再选 2 → `2,2,2` → sum=6

        - 再选 2 → sum=8 > 7 ❌ 回溯

      - 试 3 → `2,2,3` → sum=7 ✅ 收录
      - 试 6、7 都会 >7，剪枝

    - 试 3 → `2,3` → sum=5

      - 再选 3 → sum=8 ❌
      - 再选 6、7 更大 ❌

    - 试 6、7…（都超或不行）

- 选 3 开始：

  - `3` → `3,3` → `3,3,3` 都不行（>7）

- 选 6 开始：

  - `6` → 再选任何都 >7 ❌

- 选 7：

  - `7` → sum=7 ✅ 收录

最后得到：

```js
[[2, 2, 3], [7]];
```
