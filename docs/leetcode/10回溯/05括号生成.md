# 括号生成

## TOPIC

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

 

### 示例 1：

输入：`n = 3`
输出：`["((()))","(()())","(())()","()(())","()()()"]`
### 示例 2：

输入：`n = 1`
输出：`["()"]`
# 解

 这是 LeetCode 22. 括号生成（Generate Parentheses），公认的**回溯算法面试最经典题之一**！

题目要求：给出 `n` 对括号，生成所有**合法**的括号组合。

**示例：n = 3**  
输出：
```js
[
  "((()))",
  "(()())",
  "(())()",
  "()(())",
  "()()()"
]
```

---

### 最优解法：回溯 + 剪枝（面试必背！）

```javascript
/**
 * @param {number} n
 * @return {string[]}
 */
var generateParenthesis = function(n) {
    const res = [];

    // left: 已用的左括号数, right: 已用的右括号数
    const backtrack = (path, left, right) => {
        // 剪枝1：右括号不能比左括号多（不合法）
        if (right > left) return;
        // 剪枝2：总数超过 n 对
        if (left > n || right > n) return;

        // 成功条件：用完 n 对括号
        if (left === n && right === n) {
            res.push(path);
            return;
        }

        // 选择1：加一个左括号（只要还没用满）
        if (left < n) {
            backtrack(path + '(', left + 1, right);
        }

        // 选择2：加一个右括号（只要右括号不多于左括号）
        if (right < left) {
            backtrack(path + ')', left, right + 1);
        }
    };

    backtrack('', 0, 0);
    return res;
};
```

### 为什么能保证“只生成合法括号”？

| 剪枝条件             | 作用                                   |
|----------------------|----------------------------------------|
| `right > left`       | 右括号永远不能比左括号多 → 非法前缀直接剪掉 |
| `left > n`           | 左括号不能超                    |
| `right < left` 时才能加 ) | 保证任何时候左括号都够用才能闭合        |

→ 这三个条件保证了**所有生成的字符串都是**合法括号序列**！

---

### 终极口诀（面试闭眼写！）

> “左右括号各 n 个，  
> 左括号随便加（没超就行），  
> 右括号必须在左括号数量大于等于它时才能加，  
> 走到 left==n && right==n 就成功！”

---

### 最终推荐代码（最简洁 + 最快）

```js
var generateParenthesis = function(n) {
    const res = [];
    
    const dfs = (s, left, right) => {
        if (left > n || right > left) return;
        if (left === n && right === n) {
            res.push(s);
            return;
        }
        
        if (left < n)  dfs(s + '(', left + 1, right);
        if (right < left) dfs(s + ')', left, right + 1);
    };
    
    dfs('', 0, 0);
    return res;
};
```

时间复杂度：O(4ⁿ / √n) （卡特兰数相关）  
空间复杂度：O(n) 递归栈

## 🧠 思路（回溯 + 计数左右括号）

我们用递归构造所有可能的括号串，规则：

* 用两个计数：

  * `left`：已经使用了多少个 `'('`
  * `right`：已经使用了多少个 `')'`
* 约束条件：

  1. 左括号数量最多是 `n`：`left < n` 时可以继续放 `'('`
  2. 任意前缀中，右括号不能多于左括号：也就是只有在 `right < left` 时才能放 `')'`
* 当字符串长度为 `2 * n` 时，得到一个合法结果。

---

## ✅ 代码实现（JavaScript）

```js
/**
 * @param {number} n
 * @return {string[]}
 */
var generateParenthesis = function(n) {
    const res = [];

    const backtrack = (path, left, right) => {
        // path: 当前构造的括号字符串
        // left: 已经用掉的 '(' 数量
        // right: 已经用掉的 ')' 数量

        // 长度到 2n，收集结果
        if (path.length === 2 * n) {
            res.push(path);
            return;
        }

        // 还能放左括号，就放一个 '('
        if (left < n) {
            backtrack(path + '(', left + 1, right);
        }

        // 右括号数量必须小于左括号时，才能放 ')'
        if (right < left) {
            backtrack(path + ')', left, right + 1);
        }
    };

    backtrack('', 0, 0);
    return res;
};
```

# ✅ 最简单实现（只用 for + if）

```js
/**
 * @param {string} s
 * @return {boolean}
 */
var isValid = function(s) {
    const stack = [];

    for (let i = 0; i < s.length; i++) {
        const ch = s[i];

        if (ch === '(' || ch === '{' || ch === '[') {
            stack.push(ch);
        } else {
            // 如果是右括号
            if (stack.length === 0) return false;

            const top = stack.pop();

            if (ch === ')' && top !== '(') return false;
            if (ch === ']' && top !== '[') return false;
            if (ch === '}' && top !== '{') return false;
        }
    }

    return stack.length === 0;
};
```
