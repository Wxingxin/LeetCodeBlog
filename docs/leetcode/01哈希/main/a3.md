### 示例 1：

输入：`nums = [100,4,200,1,3,2]`

输出：`4`

解释：最长数字连续序列是 `[1, 2, 3, 4]`。它的长度为 `4`。

### 示例 2：

输入：`nums = [0,3,7,2,5,8,4,6,0,1]`

输出：`9`

### 示例 3：

输入：`nums = [1,0,1,2]`

输出：`3`

## Solving Problems One

### CODE

```js
var longestConsecutive = function (nums) {
  //1-1 （对题目的提前判断） 如果 nums的长度 <= 1, 返回 nums的长度
  if (nums.length <= 1) return nums.length;

  //1-2 创建numsSet 这个集合
  const numsSet = new Set(nums);

  //1-3 定义最长的距离， 用来最后的返回值
  let longestStreak = 0;

  //2 定义一个for循环
  for (let num of numsSet) {
    //2-1 只有当 num-1 不存在时，才是序列起点
    if (!numsSet.has(num - 1)) {
      let currentNum = num;
      let currentStreak = 1;

      //2-2 向右连续延伸
      while (numsSet.has(currentNum + 1)) {
        currentNum += 1;
        currentStreak += 1;
      }

      //2-3 比较每一轮的currentStreak，如果比之前的longestStreak长，就赋值给longestStreak
      longestStreak = Math.max(longestStreak, currentStreak);
    }
  }

  //3 返回最长的距离
  return longestStreak;
};
```

# 解释

# 🔍 **最长连续序列算法详细解析**

## 🎯 **问题理解**

**目标**：找到数组中最长的**连续数字序列**长度

```
输入: [100,4,200,1,3,2]
输出: 4    // 因为 [1,2,3,4] 是最长的连续序列
```

**约束**：必须 **O(n)** 时间复杂度！

## 📋 **代码逐行解析**

### **1. 边界情况处理**

```javascript
if (nums.length <= 1) return nums.length;
```

```javascript
[]    → 0
[5]   → 1
```

**为什么？** 空数组或单元素数组，最长序列就是自身长度。

### **2. 创建哈希集合**

```javascript
const numsSet = new Set(nums);
```

**作用**：

- **去重**：`[1,2,2,3]` → `{1,2,3}`
- **O(1) 查询**：`numsSet.has(x)` 瞬间判断数字是否存在

```
nums:     [100,4,200,1,3,2,2]
numsSet:   {100,4,200,1,3,2}  ← 自动去重
```

### **3. 核心算法逻辑**

```javascript
for (let num of numsSet) {
  // 只有当 num-1 不存在时，才是序列起点
  if (!numsSet.has(num - 1)) {
    // 从起点开始向右延伸
    let currentNum = num;
    let currentStreak = 1;

    while (numsSet.has(currentNum + 1)) {
      currentNum += 1;
      currentStreak += 1;
    }

    longestStreak = Math.max(longestStreak, currentStreak);
  }
}
```

## 🎨 **核心技巧详解**

### **❓ 为什么只从"序列起点"开始？**

```
数组: [1,2,3,4,5]

❌ 错误做法（O(n²)）：
1→2→3→4→5 (5次)
2→3→4→5   (4次)  ← 重复！
3→4→5     (3次)  ← 重复！
↓
每个数字都重复计算 → 超时！

✅ 正确做法（O(n)）：
1→2→3→4→5 (5次)
2: 1存在 → 跳过
3: 2存在 → 跳过
↓
每个数字只访问1次 → O(n)！
```

### **🔍 "序列起点"的定义**

```
序列起点 = "没有前驱的数字"
1 是起点（0不存在）
2 不是起点（1存在）
3 不是起点（2存在）
```


## ⚡ **时间复杂度证明**

```
1. 创建 Set: O(n)
2. 遍历 n 个数字:
   ├─ 检查 num-1: O(1)
   ├─ 从起点延伸:
   │    └─ 每个数字最多被访问1次 → O(n)
3. 总计: O(n) + O(n) = O(n)
```

**关键**：**每个数字最多被访问 1 次！**

```
- 起点数字：被while循环访问1次
- 非起点数字：只被if条件检查1次
→ 总访问次数 = n
```

## 💡 **常见错误及避免**

### ❌ **错误 1：从每个数字开始**

```javascript
// O(n²) → 超时！
for (let num of nums) {
  let streak = 1;
  while (numsSet.has(num + streak)) streak++;
}
```

### ❌ **错误 2：忘记去重**

```javascript
// [1,1,2] 会重复计算
for (let num of nums) {  // ❌ 重复遍历1
```

### ✅ **正确写法要点**

1. **用 Set 遍历**（去重 + O(1) 查询）
2. **只从起点开始**（`!numsSet.has(num-1)`）
3. **向右延伸**（`while(numsSet.has(currentNum+1))`）

**算法精髓**：**"只从序列起点开始延伸"** → **消除重复计算** → **O(n) 时间复杂度**！
