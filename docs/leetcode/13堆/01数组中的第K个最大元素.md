# 数组中的第K个最大元素

## TOPIC

- 给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

- 请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

- 你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

### 示例 1:

输入: `[3,2,1,5,6,4]`, `k = 2`
输出: 5
### 示例 2:

输入: `[3,2,3,1,2,4,5,5,6]`, `k = 4`
输出: 4

# 解

**题目**：LeetCode 215. Kth Largest Element in an Array  
**要求**：时间复杂度 **O(n)**（平均），返回数组中第 `k` 大的元素。

最经典、最推荐、最稳的解法就是 **快速选择（QuickSelect）** —— 基于「快速排序」的分区思想。

---

### 推荐写法（面试手撕必备，99% 的公司都认这个）

```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var findKthLargest = function (nums, k) {
  // 第 k 大 = 排序后倒数第 k 个 = 正序下标为 n-k 的元素
  return quickSelect(nums, 0, nums.length - 1, nums.length - k);
};

function quickSelect(arr, left, right, targetIdx) {
  if (left >= right) return arr[left];

  const pivotIdx = partition(arr, left, right);

  if (pivotIdx === targetIdx) {
    return arr[pivotIdx];
  } else if (pivotIdx > targetIdx) {
    // 目标在左半区
    return quickSelect(arr, left, pivotIdx - 1, targetIdx);
  } else {
    // 目标在右半区
    return quickSelect(arr, pivotIdx + 1, right, targetIdx);
  }
}

// Hoare 分区（双指针），返回 pivot 最终位置
function partition(arr, left, right) {
  const pivot = arr[left]; // 选最左边为基准
  let i = left;
  let j = right + 1;

  while (true) {
    while (arr[++i] < pivot) if (i === right) break;
    while (arr[--j] > pivot) if (j === left) break;

    if (i >= j) break;

    [arr[i], arr[j]] = [arr[j], arr[i]];
  }

  // 把 pivot 放回正确位置
  [arr[left], arr[j]] = [arr[j], arr[left]];
  return j;
}
```

| 步骤 | 当前区间 [L,R] | 选的 pivot | 分区后 pivot 位置 | pivot 值 | 目标下标 5 在哪边？ | 下一轮区间 |

### 为什么平均时间是 O(n)？

每次分区后，我们**至少**淘汰掉一侧区间（最坏 1/2，最好几乎全部），  
递归深度平均是 log n，但每次处理 n + n/2 + n/4 + … = O(n) → **平均 O(n)**  
最坏情况 O(n²)，但实际极少发生（随机选 pivot 可彻底避免）

---

### 更稳的写法（随机化 QuickSelect，防止最坏情况）

```javascript
var findKthLargest = function (nums, k) {
  const targetIdx = nums.length - k;
  shuffle(nums); // 随机打乱，彻底避免最坏情况
  return quickSelect(nums, 0, nums.length - 1, targetIdx);
};

function shuffle(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
}
```

#

要在 **O(n)** 平均时间复杂度下找到「第 k 大」元素，最经典的方法就是 **Quickselect（快速选择）**，它是快速排序的变种，但只递归一侧，因此平均 O(n)。

---

# ✅ 思路（Quickselect 快速选择）

- 第 k 大元素，就是排序后下标为 `n - k` 的元素（0-based）。
- 使用快速选择：

  - 随机选一个 pivot（可不写随机也能过）。
  - 把数组分区：比 pivot 小的放左边，比 pivot 大的放右边。
  - pivot 的位置 `p` 和 `target = n - k` 作比较：

    - 如果 `p == target` → 找到结果
    - 如果 `p < target` → 去右边找
    - 如果 `p > target` → 去左边找

Quickselect 的平均复杂度 **O(n)**。

---

# ✅ 代码（JavaScript — Quickselect）

```js
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var findKthLargest = function (nums, k) {
  const target = nums.length - k; // 第 k 大对应的下标

  function partition(left, right) {
    const pivot = nums[right]; // 选最后一个作为 pivot
    let i = left;

    for (let j = left; j < right; j++) {
      if (nums[j] <= pivot) {
        [nums[i], nums[j]] = [nums[j], nums[i]];
        i++;
      }
    }

    // 把 pivot 放到正确位置
    [nums[i], nums[right]] = [nums[right], nums[i]];
    return i; // 返回 pivot 的最终位置
  }

  function quickSelect(left, right) {
    if (left === right) return nums[left];

    const p = partition(left, right);

    if (p === target) return nums[p];
    else if (p < target) return quickSelect(p + 1, right);
    else return quickSelect(left, p - 1);
  }

  return quickSelect(0, nums.length - 1);
};
```
