# 字符串解码
## TOPIC

给定一个包含**红色**、**白色**和**蓝色**、共 `n `个元素的数组 `nums` ，原地 对它们进行排序，

使得**相同颜色**的元素**相邻**，并按照**红色、白色、蓝色** 顺序排列。

我们使用整数 `0、 1 和 2` 分别表示 **红色、白色和蓝色**。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

### 示例 1：

输入：nums = `[2,0,2,1,1,0]`

输出：`[0,0,1,1,2,2]`

### 示例 2：

输入：nums =` [2,0,1]`

输出：`[0,1,2]`

#

可以用「栈」很优雅地解决这个题 👍

思路简要说下：

- 用两个栈：

  - `numStack`：保存重复次数 k
  - `strStack`：保存当前构建的字符串

- 再用：

  - `currentNum`：当前正在解析的数字（可能是多位，比如 "12[ab]"）
  - `currentStr`：当前正在构建的字符串

遍历字符串 `s` 中的每个字符：

1. **如果是数字**：更新 `currentNum = currentNum * 10 + (当前数字)`

   - 这样就能处理多位数，比如 "12[abc]"

2. **如果是字母**：把它加到 `currentStr` 后面

3. **如果是 `[`**：

   - 把当前的 `currentNum` 压入 `numStack`
   - 把当前的 `currentStr` 压入 `strStack`
   - 然后重置 `currentNum = 0`，`currentStr = ""`，开始处理中括号里的新一层字符串

4. **如果是 `]`**：

   - 说明当前 `currentStr` 是 `encoded_string`
   - 弹出一个数字 `k`：`repeatTimes = numStack.pop()`
   - 弹出上一层的字符串 `prevStr = strStack.pop()`
   - 解码：`currentStr = prevStr + currentStr.repeat(repeatTimes)`

遍历结束后，`currentStr` 就是结果。

---

### 代码实现（JavaScript）

```js
/**
 * @param {string} s
 * @return {string}
 */
var decodeString = function (s) {
  let numStack = []; // 存放数字 k
  let strStack = []; // 存放之前的字符串
  let currentNum = 0; // 当前正在解析的数字
  let currentStr = ""; // 当前正在构建的字符串

  for (let ch of s) {
    if (ch >= "0" && ch <= "9") {
      // 处理多位数
      currentNum = currentNum * 10 + (ch.charCodeAt(0) - "0".charCodeAt(0));
    } else if (ch === "[") {
      // 把当前状态压栈，开始新的一层
      numStack.push(currentNum);
      strStack.push(currentStr);
      // 重置
      currentNum = 0;
      currentStr = "";
    } else if (ch === "]") {
      // 当前层结束，弹栈进行拼接
      let repeatTimes = numStack.pop();
      let prevStr = strStack.pop();
      currentStr = prevStr + currentStr.repeat(repeatTimes);
    } else {
      // 普通字母
      currentStr += ch;
    }
  }

  return currentStr;
};
```

---

### 用示例测试一下

- 输入：`"3[a]2[bc]"`

过程大致是：

- 读到 `3` → `currentNum = 3`
- 读到 `[` → 压栈：`numStack = [3]`，`strStack = [""]`，重置
- 读到 `a` → `currentStr = "a"`
- 读到 `]` → 弹出：`repeatTimes = 3`，`prevStr = ""`
  得到：`currentStr = "" + "a".repeat(3) = "aaa"`
- 读到 `2` → `currentNum = 2`
- 读到 `[` → 压栈：`numStack = [2]`，`strStack = ["aaa"]`，重置
- 读到 `b`、`c` → `currentStr = "bc"`
- 读到 `]` → 弹出：`repeatTimes = 2`，`prevStr = "aaa"`
  得到：`currentStr = "aaa" + "bc".repeat(2) = "aaabcbc"`

最终返回：`"aaabcbc"`
