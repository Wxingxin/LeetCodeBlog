# 最小栈
## TOPIC

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

`MinStack()` 初始化堆栈对象。

`void push(int val)` 将元素 val 推入堆栈。

`void pop() `删除堆栈顶部的元素。

`int top()` 获取堆栈顶部的元素。

`int getMin() `获取堆栈中的最小元素。

### 示例 1:

输入：

`["MinStack","push","push","push","getMin","pop","top","getMin"]`

`[[],[-2],[0],[-3],[],[],[],[]]`

输出：

`[null,null,null,null,-3,null,0,-2]`

解释：

```js
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
```

# 解

这是 LeetCode 第 155 题：「最小栈」（MinStack），**面试超高频**！

要求：所有操作（push、pop、top、getMin）都要 **O(1) 时间**！

### 终极最优解：一个栈 + 同步维护最小值（推荐！空间最优）

```javascript
var MinStack = function () {
  this.stack = []; // 主栈：存实际元素
  this.minStack = []; // 辅助栈：永远和主栈等长，只存“当前最小值”
};

/**
 * @param {number} val
 * @return {void}
 */
MinStack.prototype.push = function (val) {
  this.stack.push(val);

  // 如果 minStack 为空，或者新来的值更小或相等，就压入
  // 关键：相等也要压！否则 pop 后最小值会错
  if (
    this.minStack.length === 0 ||
    val <= this.minStack[this.minStack.length - 1]
  ) {
    this.minStack.push(val);
  }
};

/**
 * @return {void}
 */
MinStack.prototype.pop = function () {
  // 如果弹出的值等于当前最小值，也要从 minStack 弹出
  if (this.stack.pop() === this.minStack[this.minStack.length - 1]) {
    this.minStack.pop();
  }
};

/**
 * @return {number}
 */
MinStack.prototype.top = function () {
  return this.stack[this.stack.length - 1];
};

/**
 * @return {number}
 */
MinStack.prototype.getMin = function () {
  return this.minStack[this.minStack.length - 1];
};
```

---

### 为什么相等也要压入 minStack？

举个例子你就懂了！

```js
push(3) → stack=[3],       minStack=[3]
push(5) → stack=[3,5],     minStack=[3]          (5 > 3，不压)
push(2) → stack=[3,5,2],   minStack=[3,2]        (2 < 3，压入)
push(2) → stack=[3,5,2,2], minStack=[3,2,2]      必须压！相等也要压！
pop()   → 弹出2，stack=[3,5,2], minStack=[3,2]   正确，最小还是2
pop()   → 再弹出2，stack=[3,5],   minStack=[3]     正确，最小变成3
```

如果相等不压，第二次 pop 后 minStack 还剩 [3,2]，`getMin()` 错成 2！

### 另一种写法：只用一个栈（每个元素存一对 [val, currentMin]）

```js
var MinStack = function () {
  this.stack = [];
};

MinStack.prototype.push = function (val) {
  const min =
    this.stack.length === 0
      ? val
      : Math.min(val, this.stack[this.stack.length - 1][1]);
  this.stack.push([val, min]);
};

MinStack.prototype.pop = function () {
  this.stack.pop();
};

MinStack.prototype.top = function () {
  return this.stack[this.stack.length - 1][0];
};

MinStack.prototype.getMin = function () {
  return this.stack[this.stack.length - 1][1];
};
```

更省空间（只有一个栈），但代码稍复杂，面试一般用第一种更清晰！

### 总结口诀（面试必背！）

> “一个栈存值，一个栈存最小，  
> 进栈时最小栈只压更小或相等的值，  
> 出栈时如果弹出的等于当前最小，也一起弹出，  
> 这样最小栈栈顶永远是当前最小值！”

#

下面给你 **最简单、最经典、面试标准答案** 的 MinStack 实现。
核心思想：

> **用两个栈：一个正常栈存所有值，一个最小栈始终保持当前最小值在栈顶。**

并且用的都是最基本的语法：构造函数 + 原型方法。

---

# ✅ 最简单可运行版本（无多余技巧、直接上手）

```js
var MinStack = function () {
  this.stack = []; // 正常栈
  this.minStack = []; // 最小值栈
};

/**
 * @param {number} val
 * @return {void}
 */
MinStack.prototype.push = function (val) {
  this.stack.push(val);

  // 如果 minStack 为空，或者 val <= 当前最小值，则压入 minStack
  if (
    this.minStack.length === 0 ||
    val <= this.minStack[this.minStack.length - 1]
  ) {
    this.minStack.push(val);
  }
};

/**
 * @return {void}
 */
MinStack.prototype.pop = function () {
  const removed = this.stack.pop();

  // 如果弹出的值等于 minStack 栈顶，则同步弹出
  if (removed === this.minStack[this.minStack.length - 1]) {
    this.minStack.pop();
  }
};

/**
 * @return {number}
 */
MinStack.prototype.top = function () {
  return this.stack[this.stack.length - 1];
};

/**
 * @return {number}
 */
MinStack.prototype.getMin = function () {
  return this.minStack[this.minStack.length - 1];
};
```

---

# 🧠 为什么要用两个栈？

### 正常栈（stack）

存储每次 push 的所有值
例如：

```
push 3 → [3]
push 5 → [3,5]
```

### 最小栈（minStack）

永远保持当前最小值在栈顶
例如：

```
push 3 → [3]
push 5 → [3]
push 2 → [3,2]
push 2 → [3,2,2]
```

pop 时如果移除的是最小值，也要同步从 minStack 里 pop 掉。

这样：

- 获取最小值 `getMin()` 时只要：

  ```
  return minStack[minStack.length - 1]
  ```

- 时间复杂度 **O(1)**
