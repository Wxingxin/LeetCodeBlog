
### 示例 1:

输入: `s = "abcabcbb"`

输出: `3`

解释: 因为无重复字符的最长子串是 `"abc"`，所以其长度为 `3`。注意 `"bca"` 和 `"cab"` 也是正确答案。

### 示例 2:

输入: `s = "bbbbb"`

输出: `1`

解释: 因为无重复字符的最长子串是 `"b"`，所以其长度为 `1`。

### 示例 3:

输入: `s = "pwwkew"`

输出: `3`

解释: 因为无重复字符的最长子串是 `"wke"`，所以其长度为 `3`。

请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

# Problem Solving One

### 推荐写法：滑动窗口 + Map（最优解！）

```javascript
/**
 * @param {string} s
 * @return {number}
 */
```
```javascript
var lengthOfLongestSubstring = function (s) {
  //1-1 辅助map ： Map 用来记录：字符 → 该字符「最后一次」出现的下标
  const map = new Map();
  //1-2 辅助指针 ： 滑动窗口左边界（起始下标）
  let left = 0;
  //1-3 返回的值 ： 记录当前找到的最长无重复子串长度
  let maxLen = 0;

  //2 for循环 ： right 是滑动窗口的右边界，不断向右扩展
  for (let right = 0; right < s.length; right++) {
    //2-1 提取字符 ：指针right 指向字符串 s 的相应一个下标，char被赋值了一个字符
    const char = s[right];

    //2-2 是否在map中 ： 如果当前字符之前出现过，并且在当前窗口范围内
    if (map.has(char)) {
      // 将左边界移动到：
      // 上一次该字符出现位置的「下一个位置」
      // 用 Math.max 是为了防止 left 回退
      left = Math.max(left, map.get(char) + 1);
    }

    //2-3  ： 新的字符加入 || 旧的字符更新当前字符的最新出现位置 
    map.set(char, right);

    //2-4 更新maxLen ： 当前窗口长度 = right - left + 1
    maxLen = Math.max(maxLen, right - left + 1);
  }

  //3 返回 ： 返回最长无重复子串的长度
  return maxLen;
};
```

**时间复杂度**：O(n)  
**空间复杂度**：O(min(m, n))，m 是字符集大小（最坏 128）

### 为什么用 Map 而不是对象？

```js
// 用 Map 更好，因为：
const map = new Map();
map.set("a", 1);
map.has("a"); // true
map.get("a"); // 1
map.delete("a");

// 对象容易出问题：如果字符串有 "hasOwnProperty" 这种 key 就炸了
```

### 更简洁的写法（大佬写法）

```javascript
var lengthOfLongestSubstring = function (s) {
  let left = 0,
    maxLen = 0;
  const lastSeen = new Map();

  for (let right = 0; right < s.length; right++) {
    if (lastSeen.has(s[right])) {
      left = Math.max(left, lastSeen.get(s[right]) + 1);
    }
    lastSeen.set(s[right], right);
    maxLen = Math.max(maxLen, right - left + 1);
  }
  return maxLen;
};
```

### 核心思想总结（背下来！）

> 用一个哈希表记录每个字符最后出现的位置  
> 用 left 表示当前窗口左边界  
> 当遇到重复字符时，把 left 跳到「上一次出现位置的下一位」  
> 每次更新窗口长度，取最大值

# Problem Solving Two


## 一、逐行代码注释（在你原代码基础上）

```js
/**
 * @param {string} s  // 输入字符串
 * @return {number}   // 返回最长不重复子串的长度
 */
function lengthOfLongestSubstring(s) {
  // 用 Set 存放当前窗口中的字符（保证不重复）
  let set = new Set();

  // left：滑动窗口左边界
  // maxLen：记录历史最大长度
  let left = 0, maxLen = 0;

  // right：滑动窗口右边界，不断向右扩展
  for (let right = 0; right < s.length; right++) {

    // 如果当前字符已经在 set 中，说明出现重复
    // 需要不断移动 left，直到重复字符被移除
    while (set.has(s[right])) {
      set.delete(s[left]); // 移除左边界对应字符
      left++;              // 左边界右移
    }

    // 当前字符加入窗口
    set.add(s[right]);

    // 更新最大长度：当前窗口长度 = right - left + 1
    maxLen = Math.max(maxLen, right - left + 1);
  }

  return maxLen;
}
```

---

## 二、核心思路总结（面试 / 汇报可直接说）

### 这是一个「滑动窗口（Sliding Window）」问题

**目标**：

> 找到一个连续子串，使其中字符 **不重复**，并且 **长度最大**

### 核心思想一句话版

> 用两个指针维护一个不含重复字符的窗口，
> 右指针负责扩张，左指针负责在出现重复时收缩。

### 数据结构选择

| 组件       | 作用            |
| -------- | ------------- |
| `Set`    | O(1) 判断字符是否重复 |
| `left`   | 窗口左边界         |
| `right`  | 窗口右边界         |
| `maxLen` | 记录最大窗口长度      |

---

## 三、结合案例详细推演（**重点，一定要会讲**）

### 示例：`s = "abcabcbb"`

我们一步一步来 👇

| right | 字符 | set 内容  | left | 当前窗口  | maxLen |
| ----- | -- | ------- | ---- | ----- | ------ |
| 0     | a  | {a}     | 0    | "a"   | 1      |
| 1     | b  | {a,b}   | 0    | "ab"  | 2      |
| 2     | c  | {a,b,c} | 0    | "abc" | 3      |
| 3     | a  | ❌ 重复    | 0→1  | "bca" | 3      |
| 4     | b  | ❌ 重复    | 1→2  | "cab" | 3      |
| 5     | c  | ❌ 重复    | 2→3  | "abc" | 3      |
| 6     | b  | ❌ 重复    | 3→5  | "cb"  | 3      |
| 7     | b  | ❌ 重复    | 5→7  | "b"   | 3      |

### 关键点解释

* **right 只增不减** → 保证线性扫描
* **left 只在出现重复时移动**
* `while` 是关键，不是 `if`

  * 因为可能要移除多个字符，直到重复消失

最终答案：`3`（"abc"）

## 四、为什么一定要用 `while` 而不是 `if`

❌ 错误写法（常见新手坑）：

```js
if (set.has(s[right])) {
  set.delete(s[left]);
  left++;
}
```

**问题**：
当窗口里有多个重复时，只删一次不够。

✅ 正确原因：

```js
while (set.has(s[right])) {
  set.delete(s[left]);
  left++;
}
```

👉 **一直缩小窗口，直到合法为止**

## 五、时间复杂度 & 空间复杂度（面试必答）

### 时间复杂度：`O(n)`

* 每个字符最多：

  * 被 `right` 加入一次
  * 被 `left` 删除一次

### 空间复杂度：`O(min(n, 字符集大小))`

* Set 最多存所有不同字符
