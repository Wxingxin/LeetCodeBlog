# 插入排序

## 插入排序的基础

> **把数组分成「已排序区间」和「未排序区间」，每次从未排序区取一个数，插入到已排序区的正确位置。**

📌 类比记忆：
👉 **打牌时整理手牌**（一张一张插入）

### 特点：

- 原地排序
- 稳定
- 小数据非常快



### 插入排序的直观理解（白话）

数组：

```js
[5, 3, 4, 1, 2];
```

### 排序过程（默认第 0 位已排好）

1️⃣ `[5] | 3 4 1 2`
👉 插入 3 → `[3, 5]`

2️⃣ `[3, 5] | 4 1 2`
👉 插入 4 → `[3, 4, 5]`

3️⃣ `[3, 4, 5] | 1 2`
👉 插入 1 → `[1, 3, 4, 5]`

4️⃣ `[1, 3, 4, 5] | 2`
👉 插入 2 → `[1, 2, 3, 4, 5]`

📌 **左边始终有序，右边逐渐减少**

## code

### JS 标准实现（面试最推荐）

```js
function insertionSort(arr) {
  //1 数组属性
  const n = arr.length;

//for循环 第一个跳过， 
  for (let i = 1; i < n; i++) {
    //current赋值循环arr的指向的值，先放着 以后要使用
    let current = arr[i];
    //当前指针前一个位置
    let j = i - 1;

    // 向右移动比 current 大的元素
    while (j >= 0 && arr[j] > current) {
      arr[j + 1] = arr[j];
      j--;
    }

    // 插入到正确位置
    arr[j + 1] = current;
  }

  return arr;
}
```

## 你现在应该**真正看懂的 3 个关键点**

1️⃣ **while 里不是交换，是“整体右移”**

```text
不是 swap，而是：arr[j+1] = arr[j]
```

2️⃣ **current 一直被“拿在手里”**

```text
current 不参与移动，最后只插一次
```

3️⃣ **插入位置永远是 j + 1**

```text
因为 j 停下来的位置是：<= current
```



# 九、常见易错点（必看）

❌ **忘记保存 current**

```js
// 错误 ❌
while (arr[j] > arr[i]) {
  arr[j + 1] = arr[j];
}
```

✅ 正确：

```js
let current = arr[i];
```

---

❌ **while 写成 if**

```js
// ❌ 只能移动一次
if (arr[j] > current) { ... }
```

---

❌ **j + 1 写成 j**

```js
arr[j] = current; // ❌ 覆盖
```
